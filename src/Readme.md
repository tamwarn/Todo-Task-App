A task app to keep track of daily tasks and chores.

You click the button when a task has been completed. The app will keep track of tasks.

Used React, JavaScript, Visual Studio Code, GitHub, etc.

Improvements:
1. Add more tasks in the future.
2. Add illustrations to define tasks.
3. Ability to show tasks remaining.


As a user
I want to keep track of chores, so I can organize my life.

As a parent, I want to have my child keep up with chores, so I can get chores done accurately.

As a child, I want to keep up with my chores, so I can earn my allowance.
